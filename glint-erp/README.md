# Glint: Website + ERP
Buka `index.html` (website toko, botol 3D) dan `erp.html` (sistem ERP).
Tanpa instalasi, tanpa internet (font Google opsional). Data ERP tersimpan di localStorage browser.
Pesanan dari website otomatis masuk ke ERP (menu Penjualan) jika dibuka di browser yang sama.
Struktur: css/ (style.css, erp.css) · js/ (store.js, bottle3d.js, site.js, erp.js)
Nomor WhatsApp diatur di js/store.js (konstanta WA).
